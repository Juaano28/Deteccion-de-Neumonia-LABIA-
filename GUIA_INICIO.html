Clasificación de radiografías de tórax

Guía para instalar, iniciar y presentar la aplicación académica de MobileNetV2. Incluye el modelo entrenado, sus resultados y las 624 imágenes del test utilizado en el proyecto.

EmpezarAbrir la páginaImágenesLas tres pestañasAyudaRespaldo técnico
Uso académico. El sistema sirve para estudiar y demostrar la clasificación de imágenes de un conjunto de práctica. No sustituye una evaluación médica ni acredita desempeño en todas las radiografías de tórax.

1. Preparar esta entrega

Extrae Neumonia_Proyecto_Final.zip. La carpeta de trabajo se llama neumonia_app y contiene app.py, modelo/, las imágenes y los archivos de inicio.

Ya tengo la versión anterior funcionando

  1. Detén Streamlit con Ctrl+C y conserva el ZIP anterior como respaldo.
  2. Extrae la nueva entrega en una ubicación temporal.
  3. Copia el contenido de la nueva neumonia_app sobre la carpeta del proyecto que ya utilizabas. Acepta reemplazar los archivos.
  4. Conserva tu carpeta .venv en la misma ruta. El ZIP no incluye una .venv y las dependencias siguen siendo las mismas.
  5. Inicia con INICIAR_PAGINA.bat.

Usaré otra carpeta u otro computador

  1. Instala Python 3.12 de 64 bits.
  2. Extrae el ZIP completo en la ubicación donde conservarás el proyecto.
  3. Abre neumonia_app y ejecuta INSTALAR_ENTORNO.bat.
  4. Espera el mensaje INSTALACION COMPLETADA.
  5. Ejecuta INICIAR_PAGINA.bat.

La primera instalación necesita Internet y puede tardar varios minutos. Crea el entorno en esa ubicación; no copies una .venv de otra carpeta o computador.

Qué contiene el ZIP: código, pesos del modelo, metadatos, imágenes y evidencias. Las bibliotecas de Python se instalan una vez por entorno. Después de esa instalación, la inferencia funciona con los archivos locales.

Instalación manual desde PowerShell

Abre neumonia_app en Visual Studio Code y selecciona Terminal → Nueva terminal. Ejecuta cada comando cuando termine el anterior:

py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install --upgrade pip
.\.venv\Scripts\python.exe -m pip install torch==2.6.0 torchvision==0.21.0 --index-url https://download.pytorch.org/whl/cpu
.\.venv\Scripts\python.exe -m pip install -r requirements.txt

El primer comando se utiliza al crear un entorno en una ubicación nueva. Si la terminal indica que no encuentra Python 3.12, instala esa versión desde python.org y abre una terminal nueva. La extensión de Python para VS Code no instala el intérprete.

2. Abrir la página cada vez

Haz doble clic en INICIAR_PAGINA.bat. Este archivo utiliza el entorno instalado y deja el servidor abierto en una terminal.

También puedes abrir neumonia_app en VS Code, seleccionar Terminal → Nueva terminal y ejecutar:

.\.venv\Scripts\python.exe -m streamlit run app.py

Abre http://localhost:8501 en tu navegador. Si la pestaña no aparece automáticamente, escribe la dirección manualmente.

  • Mantén abierta la terminal mientras usas la aplicación.
  • Para detener el servidor, pulsa Ctrl+C en esa terminal.
  • Si solo cerraste el navegador y el servidor sigue abierto, vuelve a la dirección sin iniciar otra instancia.
  • El computador que ejecuta la página debe permanecer encendido. La configuración escucha en 127.0.0.1, para uso local.

La aplicación utiliza CPU, carga el modelo ya entrenado y procesa una imagen por solicitud. Cada inicio reutiliza la .venv; no requiere reinstalar las bibliotecas ni activar scripts de PowerShell.

El test completo también está incluido

Consulta inventario_test.csv para relacionar archivos, etiquetas y predicciones registradas, y ATRIBUCION_Y_USO.txt para conocer su fuente y condiciones de uso.

pruebas_portables/ conserva otra selección de 16 casos para comprobar la implementación. Incluye aciertos y errores conocidos; su porcentaje de aciertos no estima el desempeño general.

4. Recorrer las tres pestañas

Analizar imagen

  1. Carga una radiografía JPEG o PNG del conjunto de práctica.
  2. Observa la imagen y, si lo deseas, despliega su entrada de 224 × 224 píxeles.
  3. Pulsa Analizar imagen.
  4. Consulta la clase, el puntaje y la regla aplicada. Al cambiar la imagen, vuelve a pulsar el botón.
  5. Si deseas conservar la salida técnica, pulsa Descargar resultado (JSON).

El puntaje es un número de 0 a 1 que favorece la clase PNEUMONIA cuando aumenta; no expresa una probabilidad individual de acierto. La regla mantiene el umbral 0,8745065331459045. La clase NORMAL es una salida del clasificador y no descarta otras alteraciones.

Se admite un JPEG/PNG legible de hasta 20 MiB. DICOM, PDF e imágenes animadas quedan fuera de esta versión. La lectura correcta de un archivo no demuestra que su contenido sea una radiografía. La aplicación no guarda automáticamente la imagen ni la envía a servicios externos de IA.

Resultados del experimento

Presenta métricas fijas del test oficial: 91,03 % de exactitud, 94,10 % de sensibilidad y 85,90 % de especificidad. La matriz conserva 201 TN, 33 FP, 23 FN y 367 TP. Las tablas explican las políticas y las vistas del mismo test; los registros describen errores frente a las etiquetas del dataset.

Los resultados del experimento no se recalculan cada vez que subes una imagen. Procesar 624/624 archivos significa que se completó su lectura e inferencia; no significa 624 aciertos.

Acerca del modelo

Explica MobileNetV2, el aprendizaje por transferencia, el preprocesamiento, los parámetros y la selección de la época global 15. La selección del modelo y del umbral utilizó validación; la evaluación final empleó el test. Incluye las conclusiones y los límites de generalización.

6. Respaldo técnico y alcance

El ZIP mantiene los resultados del entrenamiento, las predicciones y los registros de comprobación. La página presenta el producto académico; los archivos de respaldo permiten examinar las decisiones y sus limitaciones.

Comprobación opcional al cambiar de equipo o de entorno
.\.venv\Scripts\python.exe verificar_instalacion.py

Compara 16 casos entre la CPU de tu instalación y las referencias CPU de Kaggle. El resultado se guarda en evidencia/verificacion_local.json. Si cambia el equipo o las bibliotecas, repetirlo permite comprobar esa instalación. No es necesario ejecutarlo cada vez que abres la página.

La instalación de Esteban aprobó los 16 casos, con diferencia máxima aproximada de 0,00000209 frente a una tolerancia de 0,0001. Esto no representa una evaluación clínica independiente.

Qué conserva la comparación histórica

La comparación GPU con precisión mixta frente a CPU float32 procesó 624 imágenes: coincidieron las 624 entradas y las 624 clases. Cinco puntajes superaron la tolerancia de 0,01, por lo que la paridad numérica histórica permanece no aprobada. Los registros originales conservan ese resultado y el verificador lo informa por separado de la comprobación CPU local.

Los paneles y el registro documentan 23 falsos negativos y 33 falsos positivos. La revisión humana figura pendiente en el registro original. No se cambiaron pesos, umbral ni preprocesamiento para preparar esta entrega.

El modelo es un prototipo académico binario. La independencia clínica por paciente permanece sin verificar y falta evaluación externa para estudiar su generalización a otras poblaciones, equipos y condiciones de adquisición.
